# This document contains the difficulties of each country's alarm, as well as additonal information. The sirens used are the EAS sirens, which are complied in [this Youtube video](https://www.youtube.com/watch?v=xFgBgtRqJS4)
The difficulties are equivalent to:
### Easy 		= Upheaval
### Medium 		= Meltdown
### Hard 		= Catastrophic
### Ultra Hard 	= Apocalypitic
